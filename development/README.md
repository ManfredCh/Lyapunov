# Development guide

Build requirements, architecture and checks are described in [Developing Lyapunov](../docs/DEVELOPMENT_STANDARDS.md). The public repository contains client source and required test/build inputs. Optional physics engines, model weights and user data are installed outside the source tree.

Use a GitHub-linked author email for commits and concise English commit messages. See [contribution guidance](../CONTRIBUTING.md), [installation](../docs/install.md) and [release notes](../docs/releases/0.1.0-alpha.4.md).
