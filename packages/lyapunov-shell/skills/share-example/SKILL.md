# 整理和分享机器人示例

保存场景、资产和许可证来源，写入所需软件、任务条件、命令、实际成败、失败重现及录像。用 `recording_export` 或 `mujoco-showcase-shot` 产出可核对的媒体。能用工作台原生分享时按用户授权范围创建预览；发布前确认工作区文件、授权和公开范围。上游 Discussions 是可选提交目的地。
