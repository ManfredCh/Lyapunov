# MuJoCo Studio 使用

用 sim_open 打开工作台世界，定位场景树对象，核对动力学和碰撞组。需要原版编辑工具时使用 MuJoCo Studio，并把 MJCF 和相机结果显式导入工作区。工作台录制参考 mujoco-studio-sidecar。
