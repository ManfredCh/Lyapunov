# MuJoCo MjSpec 编辑

用 MjSpec 加载、修改、编译并重新定位关节／传感器 ID。把局部 XML 资源放在同一包内，核对自由关节、复制名称、include 和相对路径。导入工作台用 scene_import，修改前后跑 mujoco-audit。
