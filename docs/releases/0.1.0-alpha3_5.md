# Lyapunov 0.1.0α（Alpha3_5）发布说明

| 发布元数据 | 内容 |
| --- | --- |

Alpha3_5 以独立版本和标签提供 Linux x64 Alpha 源码。项目主许可为 [Apache License 2.0](../../LICENSE)，[NOTICE](../../NOTICE) 保留上游版权与许可声明。双语 README 保留 UAD 赞助、七位作者及 © 2026 Vorynel Co., Ltd. 的归属信息。

本版本沿用既有工作台、机器人、相机和仿真范围，包括 Linux glibc 文件锁原生载荷、原生工作台前端资源检查、Noto Sans SC 中文字体、场景创建与载入反馈，以及有限的 Newton Scene collision 路线。各引擎支持范围见[能力总表](../CAPABILITY_MATRIX.md)；设备、图形后端和具体任务按实际运行结果确认。

安装、升级与回滚见[安装手册](../install.md)。Linux 主包与默认 MuJoCo 伴随环境按实际公开批次的同一 releaseId 配对，文件名、大小、校验值与系统要求以[官网安装页](https://vorynel.com/lyapunov/)及其版本清单为准。源码标签独立标识本版本；官网安装命令继续使用官网当前公开的安装批次。
