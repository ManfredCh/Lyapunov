# Lyapunov Linux x64 Alpha（A08）发布说明

本 Alpha 聚焦场景与机器人准备流程、相机返程与自由导航、静态环境碰撞、Guest，以及客户端与资源服务的职责边界。版本标识、下载内容、校验值和最低运行要求，以官网安装页及该批次 JSON／TSV 版本清单为准。

## 本批次的具体变化

- **默认运行环境**：官网 curl 安装使用版本化主包与 MuJoCo 伴随包。主包内的 Node／DSH 与该版本独立 MuJoCo Python 环境各自保存，运行环境迁移、依赖与原生物理检查通过后才激活 `current`；安装失败保留旧版本与用户数据。
- **机器人准备基线**：场景模板的初始暂停状态传递到物理世界。各机器人按“准备 → 初始化 → 就绪 → 显式受控执行”操作，保留不同型号与引擎的控制映射和依赖条件。
- **相机与导航**：相机面板可进入已保存视角，并通过“返回主视图”或 `Esc` 恢复完整主机位；固定／绑定相机使用相同返程。修复世界状态、代次或 Scene 刷新清除自由漫游按键的问题；WASD／Q/E 按 Viewer 焦点接收，失焦停止。
- **通用静态碰撞**：静态／环境的默认非凸碰撞使用源表面生成的未填充表面盒，保留室内空区、孔洞与腔体。动态对象与显式 CoACD 路径保留。原 B1 的选定完整节点已完成几何生成，整体场景与世界运行范围见下文。
- **Guest 与账户**：欢迎页提供官网授权登录和显式 Guest。正式模型经 Peiri 中转并使用中央 Credits；Guest 使用独立本地工程，不连接产品账户或计费后端，没有默认模型。Agent 使用需要用户显式配置自己的 provider，本地文件、Scene、Viewer 与已安装工具可用。
- **资源获取边界**：资源服务只提供官方项目／注册表根、来源地址和 metadata 上下文。客户端 Agent 使用 BrowserUse／WebFetch／Bash 继续读取来源、获取并校验具体文件；来源入口不自动代表任意模型或 policy 已兼容。
- **安装与手册**：应用按版本保存，升级保留旧版本和包外数据，README 与随包说明采用英文主文与简短中文辅助。默认 MuJoCo 的安装前缀支持普通路径和空格；包含单引号的前缀在下载前以 `CONDA_PREFIX_UNSUPPORTED` 拒绝。

## 平台与已知范围

本 Alpha 提供 Linux x64 路径。主包自带 Node.js、Electron、固定 DSH 与产品插件；默认 MuJoCo 环境作为版本化伴随包准备。Isaac、Newton、policy、benchmark、Blender、外部服务与模型权重按任务显式选用，其许可、硬件、SDK 和账户要求各自保留。

Intel／AMD／NVIDIA 与各发行版并未覆盖全部桌面、相机和物理组合；最低 glibc 由该批次主包与 MuJoCo 伴随包清单分别声明。本次不提供 macOS／Windows 安装包。SDK 可用、物理世界就绪和机器人任务完成仍按各自结果确认。

静态表面碰撞的厚度由 pitch 量化，不等于精确重建源材料的实体体积；所有窄孔、通道净宽和全场通行尚未普遍覆盖。原完整 B1 场景、该节点全部表面盒的完整 MuJoCo 世界与最终 GUI 行为仍未完整覆盖。相机的源码与接口行为已有修补，所有桌面原生输入与渲染组合尚未逐项覆盖。

共同初始化流程不代表 G1 自动起身，也不代表全部机器人本体行为都已实测。T0 提供官方来源根与上下文，具体模型、权重、policy 与执行能力需要逐项准备和匹配。

## 升级与数据

使用默认安装器的用户退出应用后重跑官网脚本。旧版本、`previous` 和包外数据保留；更换应用版本不自动恢复升级前的数据布局。请在升级前导出重要工程或保存实际数据根的副本，再按[安装手册](../install.md)处理回滚与卸载。
