# Lyapunov 0.2.7

本版更新机器人仿真与验证工作流，提供 Linux x64、Windows WSL2 和 macOS Apple Silicon 的下载入口。Windows 在 WSL2 的 Ubuntu 24.04+ 终端运行 Linux 安装器。macOS 提供 macOS 15+ 的 Apple Silicon 便携包，归档使用 ad-hoc 签名，尚未公证。 [官网下载安装](https://vorynel.com/lyapunov/) · [GitHub Release](https://github.com/ManfredCh/Lyapunov/releases/tag/v0.2.7)

## 本版更新

- **用同一组条件比较机器人方案。** Agent Graph 记录同种子配对、T0–T4 物理扰动、逐次任务判定、失败原因、安全结果和原生录制。已有任务仍可沿原流程运行，腕相机纠偏和安全放置检查可按任务启用。 [Agent Graph](../AGENT_GRAPH.md) · [SO-101 实验](../../research/agy-sim-234/README.md)
- **将定位、规划和验证组合到同一个机器人任务。** `robotics-composition` 统一组织双视角定位、Bi‑RRT 避障、模型审计、抓放和数据录制。YAM 六轴视觉闭环可在支持的 MuJoCo 标记场景中使用。 [组合技能说明](../../research/agy-robotics/README.md)
- **独立运行 Playground 训练和评估。** SO‑101 训练 Job 保存检查点，评估 Job 在独立 MuJoCo 环境复跑并回收逐次结果。该流程需要单独配置 Python 运行时。
- **从目标姿态生成可回放的人体片段。** 可选 SOMA 在本地生成动作补间，发布包携带接口和准备脚本，模型权重放在独立目录。用户可在扩展市场查询扩展，或在「设置 → 集成」中查看来源和安装状态。 [SOMA 准备与使用](../HUMAN_CROWD.md#可选-soma-本地动作补间)
- **补齐发行运行时。** 标准 MuJoCo 环境带有 Pillow 和 MCAP 依赖。Linux 包随固定 SDK 交付 Landlock 执行器，支持相应内核的系统可用于受限会话。

## 仿真验证范围

SO‑101 的五档扰动实验收齐 10 个有效配对，原流程和闭环组各完成 5 次入盒。六轴 YAM 的标记工位测试将图像误差从 39.60 px 降至 0.92 px。当前 Playground 检查点在独立的 6 个种子上通过 0 次，评估仍用于实验。上述结果来自指定的仿真工况。 [实验摘要与录像索引](../../research/agy-sim-234/README.md)
