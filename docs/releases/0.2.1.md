# Lyapunov 0.2.1

0.2.1 is the full Linux x64 release containing the Agent Graph product and the native settings refinement. It is a complete distribution rebuilt from the tagged source, not a local patch applied to the previous archive.

## Changes

- Integrations, Physics engine, Robot library and Downloads now use DSH's native controls, typography and theme tokens.
- Custom settings navigation uses small, consistent plug, orbit, robot arm and download icons. Native DSH settings and their background colors retain their existing appearance.
- Software, MCP integrations and skills share searchable lists; detailed diagnostics, tools and installation output are available in the relevant detail view.
- Downloads use compact name and status rows. Job output is scoped to the selected job. Available weights and runtime integration status remain distinct.
- Physics settings separate the engine overview from provider details. English engine titles initialize in the selected language.
- Robot library details use readable policy availability messages. Opening the scene from settings closes the settings dialog and reveals the native scene workspace.
- Custom theme selection follows the native settings row format.

## Included capabilities

The release retains scene and asset management, robot components and assembly, simulation, mounted cameras, Capture and Recording, and the Agent Graph campaign loop introduced in 0.2.0-alpha.1. Agent actions can evaluate task predicates, recall verified skills, and advance curriculum pointers. Worker access to heldout scenes and verifier access to proposal artifacts remain separated by code-level checks.

## Install and previous versions

The website's default Linux manifest selects 0.2.1. The installer prepares the managed MuJoCo and policy runtimes as declared by the release manifest. User account files, engine preferences and workspaces are preserved during an upgrade.
