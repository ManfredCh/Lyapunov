# Lyapunov 0.2.4.2

- 修复原生桌面的关节范围误判。关节范围至少提供一个有限的 `min` 或 `max`，两个边界同时提供时要求 `min ≤ max`。工具、斜杠命令和动作工具附带的谓词都会拒绝 `low/high` 等未声明字段。合法范围按关节实测位置判定。
- 中文关节转动指令会提示读取 `action-execution`。技能和 `joint_move` 工具说明给出世界 ID、当前代次、动作 ID、机器人 ID、关节和目标数组、动作时长及物理回读的用法。

本机通过路由回归，并使用原生工具注册器、斜杠命令与 MuJoCo 3.13.0 验证了关节运动和范围判定。生产 Peiri 和桌面图形界面尚未验收。
