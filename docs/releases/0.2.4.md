# Lyapunov 0.2.4

本版接通从控制步录制、键盘抓放到 Isaac Lab 示教导出和回放的流程，并补齐 Isaac Sim 的人群巡逻与 NuRec 场景验收。

## 录制与 Isaac Lab

- 录制逐控制步的动作与状态，保持相机观测和事件的时间对齐。Capture 支持键盘抓放并导出 Isaac Lab 可读取的 HDF5 示教。
- 在固定的 Isaac Lab v3.0.0 环境中完成 Franka 笛卡尔任务回放，五条源示教全部通过。Mimic 扩增尝试 10 次，成功 3 次，其余 7 次未达到任务成功条件。
- 上游来源、依赖版本、逐阶段验收及复现命令见 [Isaac 生态接入记录](../ISAAC_ECOSYSTEM_IMPLEMENTATION_20261110.zh-CN.md)。

## Isaac Sim 资产、人群与重建场景

- USD 资源详情支持独立的物理检查。报告绑定源文件 SHA-256 与资源版本，可核对 PhysX 配置和短步仿真结果。
- Isaac IRA 人群支持巡逻路线和区域进入、离开事件。Linux 上完成 CPU 物理、RTX 渲染的实际运行验收，并回归 MuJoCo 人群入口。详见[人群工作流](../HUMAN_CROWD.md)。
- NuRec 支持以同机位参考帧计算 PSNR 和 SSIM，并验收重建背景与机器人、动态物体共场运行。验收使用 NVIDIA 官方样本，样本和参考帧需单独提供。

## 安装平台

- 0.2.4 首批提供 Linux x64，适用于 Ubuntu 24.04 或兼容环境。Windows 通过 WSL2 和 WSLg 使用同一 Linux 包。
- macOS 独立发布。首批发布时，macOS 安装入口提供 0.2.3。Isaac Sim 和 IRA 依赖 Linux 上单独配置的 Isaac 运行环境。
- 安装器按平台选择下载清单。安装和更新入口见[官网](https://vorynel.com/lyapunov/)。
