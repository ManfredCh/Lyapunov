# Lyapunov 0.1.0-alpha.7

本版将产品固定供给的 Computer Use Linux 和已安装的 Blender MCP 交给原生客户端自动关联，保留用户现有 namespace、停用状态和配置。软件目录支持下载作业进度、已有安装复用及自然语言管理入口；Unity 连接前明确正常编辑器前置。

场景建模遵循截图、反馈、修订闭环。本版同时合入 Isaac 挂载初始化及 MuJoCo 静态三角面互碰修复。具体可用范围以正式安装与真实运行验收记录为准。

默认 Computer Use Linux 使用官方稳定版 `0.7.13`；本地修补版 `0.7.13+local.atsbus.1` 仅通过 `LYAPUNOV_COMPUTER_USE_LINUX_VARIANT=local` 显式选择，不自动切换。两份二进制、原两文件补丁、固定来源和 MIT 许可均随包保留；已有用户配置优先保留。本版支持 Ubuntu 24.04 或更新版本，两份桌面供给均要求 glibc 2.39 或更新版本。

Alpha7 supports Ubuntu 24.04 or newer with glibc 2.39 or newer. Computer Use Linux defaults to official stable version `0.7.13`. Select the optional `0.7.13+local.atsbus.1` variant explicitly with `LYAPUNOV_COMPUTER_USE_LINUX_VARIANT=local`; there is no automatic switch. Both binaries, the original two-file patch, pinned provenance and MIT license are included. Existing user configuration takes precedence, and both variants have the same minimum glibc requirement.

Linux 安装、升级和回滚见[安装手册](../install.md)。发布包与 MuJoCo 伴随包以对应 releaseId 的正式清单为准。
