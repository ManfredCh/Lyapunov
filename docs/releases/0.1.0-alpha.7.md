# Lyapunov 0.1.0-alpha.7

本版将产品固定供给的 Computer Use Linux 和已安装的 Blender MCP 交给原生客户端自动关联，保留用户现有 namespace、停用状态和配置。软件目录支持下载作业进度、已有安装复用及自然语言管理入口；Unity 连接前明确正常编辑器前置。

场景建模遵循截图、反馈、修订闭环。本版同时合入 Isaac 挂载初始化及 MuJoCo 静态三角面互碰修复。具体可用范围以正式安装与真实运行验收记录为准。

默认 Computer Use Linux 为 `0.7.13+local.atsbus.1`，修复 AT-SPI 总线选择；原两文件补丁、固定来源和 MIT 许可随包保留。仅显式设置 `LYAPUNOV_COMPUTER_USE_LINUX_VARIANT=official` 选择独立官方 0.7.13 回退入口，不因修复件失败自动降级。本版支持 Ubuntu 24.04 或更新版本，固定桌面供给要求 glibc 2.39 或更新版本；官方回退使用相同最低要求。

Alpha7 supports Ubuntu 24.04 or newer with glibc 2.39 or newer. Computer Use Linux defaults to `0.7.13+local.atsbus.1`, with the original two-file AT-SPI patch, pinned upstream provenance and MIT license included. Set `LYAPUNOV_COMPUTER_USE_LINUX_VARIANT=official` explicitly to select the independent upstream 0.7.13 entry; there is no automatic downgrade, and the official fallback has the same minimum glibc requirement.

Linux 安装、升级和回滚见[安装手册](../install.md)。发布包与 MuJoCo 伴随包以对应 releaseId 的正式清单为准。
