## English

Alpha 6.2 improves Isaac SDK setup, external tool connections, and background job feedback. MuJoCo remains the default installation path; the pinned DSH fork and Agent Graph remain the foundation of the product.

- **Isaac setup and recovery.** Explicit SDK choices and compatible managed installations from earlier product versions remain available across upgrades. Selection uses environment overrides, saved choices, then the current managed SDK. Invalid explicit choices report their cause; a failed check or unreadable settings file preserves the existing configuration. A successful managed SDK check records its path atomically.
- **Kit downloads.** The optional Isaac installer prepares the fixed Kit SDK, physics, and generic Kit extension cache packages. The generic Kit wheel is about 5.88 GB to download and 11.66 GB to unpack, in addition to other SDK and cache space. Interrupted downloads resume in verified segments; only a complete file with the pinned length and SHA256 is handed to pip. Download or verification failures stop the installation.
- **Physics and file access.** Changing the agent's permission mode preserves the physics world. World synchronization, pause, and resume keep their normal controls, while captures and exports check the current file authorization separately. Denied output requests report the affected operation without ending the world. Existing worlds retain their original file access; changing the mode alone does not make new output locations available. A saved scene with one valid infinite ground can open without an extra persistent scene edit.
- **External tools and MCP.** Settings can inspect existing software and configure native MCP connections without a language model. Software installation, editor addons, connection state, discovered tools, and completed calls are shown separately. Existing connection fields, credentials, and custom Blender ports are preserved unless explicitly changed. Blender and Unity MCP bridges are third-party integrations; their editor addons must be prepared and enabled separately. Routing prefers actually discovered, applicable MCP tools and retains `blender_run` for batch work.
- **Optional downloads.** Catalogued model acquisition uses `hf-mirror.com`, requires an available hf CLI and a writable destination, and reports missing access or files without changing to the official endpoint. Downloaded weights do not establish inference readiness. SAM 3 has a local adapter; SAM 3D Objects has no product runtime adapter, and DA3 downloads do not replace the current DA-V2 depth adapter. FastGS continues to use its existing source and isolated environment workflow.
- **Background jobs.** Blender input paths resolve against the real session workspace and are checked before the job starts. Standard output and errors feed the existing job output stream. The render flag controls additional product preview renders; a supplied Python script may render independently. Preview images are reported only from actual completed results. The execution graph explains when the model loop is idle while an independently submitted background job is still running; pausing a Goal does not pause that job.

Existing Isaac installations must match Isaac Sim 6.0.1 / 6.0.1.0 and Python 3.12. SDK discovery or installation is distinct from successful Kit, PhysX, or RTX execution. See the [Isaac setup guide](../isaac-setup.en.md), [installation guide](https://vorynel.com/lyapunov/guide.html), and published release manifests for requirements and exact downloads.

## 中文

Alpha6.2 改进 Isaac SDK 准备、外部工具连接与后台作业反馈。默认安装仍准备 MuJoCo，固定的自有 DSH fork 与 Agent Graph 继续作为产品底座。

- **Isaac 准备与恢复。** 显式 SDK 选择和旧产品版本中的兼容 managed 安装可跨升级使用，选择依次读取环境覆盖、已保存选择和当前 managed SDK。失效的显式选择说明具体原因；检查失败或配置不可读时保留原配置，managed SDK 检查成功后才原子记录路径。
- **Kit 下载。** 可选 Isaac 安装器准备固定的 Kit SDK、physics 与通用 Kit 扩展缓存。通用 Kit wheel 下载约 5.88GB，解压约 11.66GB，此外还需其他 SDK 与缓存空间。中断后按已验证分段续传，完整长度和 SHA256 匹配后才交给 pip；下载或校验失败时停止安装。
- **物理与文件权限。** 改变 Agent 权限模式保留物理世界，世界同步、暂停和继续仍走正常控制；截图与导出分别核对当前文件授权。输出请求被拒时说明对应操作，不结束世界。已有世界保留原文件访问范围，单纯改变模式不会自动开放新的输出目录。已保存且含单一有效无限地面的场景可以直接打开物理世界，无需额外持久场景编辑。
- **外部工具与 MCP。** 设置可以在没有语言模型时检查已有软件、配置原生 MCP，分别显示软件安装、编辑器 addon、连接状态、已发现工具和实际调用。已有连接字段、凭据和 Blender 自定义端口在未显式修改时保留。Blender 与 Unity 的 MCP 桥接属于第三方整合，编辑器 addon 须分别准备与启用。路由优先使用实际已发现且适用的 MCP 工具，并保留 `blender_run` 批处理路径。
- **可选下载。** 目录登记的模型取得使用 `hf-mirror.com`，需要可用 hf CLI 和可写目录；缺少访问授权或文件时报告具体问题，不切官方端点。权重下载不代表推理就绪。SAM3 有本地适配器，SAM3D Objects 尚无产品运行适配器，DA3 下载不会替换当前 DA-V2 深度适配器。FastGS 继续使用既有源码与隔离环境流程。
- **后台作业。** Blender 输入按会话真实工作区解析，启动前检查文件存在；stdout 与错误进入既有 job 输出流。render 控制产品附加预览，用户 Python 脚本仍可自行渲染；预览图片只根据实际完成结果报告。执行图说明模型循环未运行但独立后台作业仍运行的情况，暂停 Goal 不会暂停该作业。

已有 Isaac 安装须匹配 Isaac Sim 6.0.1 / 6.0.1.0 与 Python3.12。SDK 发现或安装与真实 Kit、PhysX、RTX 执行分别判断。系统要求与精确下载见[Isaac说明](../isaac-setup.md)、[安装手册](https://vorynel.com/lyapunov/guide.html)及实际发布清单。
