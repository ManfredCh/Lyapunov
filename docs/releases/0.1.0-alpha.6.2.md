# Lyapunov 0.1.0-alpha.6.2

[English README](../../README.md) · [中文 README](../../README.zh-CN.md)

## English

This release corrects Isaac SDK selection and recovery while keeping the owned DSH fork, Agent Graph and default MuJoCo runtime unchanged.

- Missing Isaac installations report the SDK setup problem instead of suggesting that an empty scene is an invalid request. The scene and its infinite ground remain saved.
- Local discovery includes compatible Isaac environments inside older product versions. It remains bounded and changes nothing until an installation is selected.
- The managed Isaac installer saves its verified SDK path for future product upgrades. A failed SDK check or an unreadable settings file does not register a new choice; existing overrides and saved installations are preserved.
- The managed Isaac installer requests only the extension caches the current physics runtime needs (`isaacsim-extscache-kit-sdk` and `isaacsim-extscache-physics`) instead of the full `extscache` group, so it no longer depends on the multi-gigabyte generic Kit cache download. Extensions that are not cached still resolve online on first use.
- SDK selection, discovery and the missing-SDK physics status have matching Chinese and English text.

Existing standalone installations and Python environments must match Isaac Sim 6.0.1 / 6.0.1.0 and Python 3.12. SDK discovery does not establish successful Kit, PhysX or RTX execution. See the [Isaac setup guide](../isaac-setup.en.md).

For help, email [voryneltech@gmail.com](mailto:voryneltech@gmail.com), report reproducible problems in [Issues](https://github.com/ManfredCh/Lyapunov/issues), or discuss improvements in [Discussions](https://github.com/ManfredCh/Lyapunov/discussions).

## 中文

此版本修复 Isaac SDK 的选择与恢复，保留自有 DSH fork、Agent Graph 和默认 MuJoCo 环境。

- 缺少 Isaac 时明确说明 SDK 准备问题，不再把空白场景说成无效请求；场景与无限地面仍保留。
- 已有安装发现包括旧产品版本中的兼容 Isaac 环境；扫描有界，选择前不改变任何设置。
- 产品安装器在 SDK 检查成功后保存路径，供后续版本升级读取。检查失败或配置不可读时不登记新的选择，已有覆盖与保存选择保留。
- 产品 Isaac 安装器只请求当前物理运行需要的扩展缓存（`isaacsim-extscache-kit-sdk` 与 `isaacsim-extscache-physics`），不再请求整个 `extscache` 组，因此不再依赖数 GB 的通用 Kit 缓存下载。未缓存的扩展首次使用时仍按官方索引联网解析。
- SDK 选择、发现与缺 SDK 的物理状态提供对应中文和英文。

已有 standalone 或 Python 环境须匹配 Isaac Sim 6.0.1 / 6.0.1.0 与 Python 3.12。发现 SDK 不代表 Kit、PhysX 或 RTX 已成功执行。详见 [Isaac 安装与选择说明](../isaac-setup.md)。

遇到问题请联系 [voryneltech@gmail.com](mailto:voryneltech@gmail.com)，通过 [Issues](https://github.com/ManfredCh/Lyapunov/issues)反馈复现步骤，并在 [Discussions](https://github.com/ManfredCh/Lyapunov/discussions)交流改进建议。
