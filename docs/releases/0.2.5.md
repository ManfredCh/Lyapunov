# Lyapunov 0.2.5

- 工作台使用原生场景、文件与终端标签。移除旧内嵌对话布局和未开放的执行图页面。后台作业身份核对、失败恢复与 `execution_status` 继续可用。
- Viewer 的碰撞显示沿用物理引擎提供的拓扑。源码包移除旧碰撞线框与未接入正式重建流程的照片点云配准实现。

## 下载与安装

- Linux x64 与 Windows WSL2 共用 `0.2.5-linux-4a5f3b79`。Windows 用户在 WSL2 的 Ubuntu 24.04+ 终端执行安装命令。[版本清单](https://vorynel.com/lyapunov/releases/0.2.5-linux-4a5f3b79/linux-x64.json)
- macOS Apple Silicon 下载以官网的 macOS 清单为准。[官网安装页](https://vorynel.com/lyapunov/)

```sh
curl -fsSL https://vorynel.com/lyapunov/install.sh | sh
"$HOME/.local/bin/lyapunov"
```

Linux x64 从独立解包目录核对了产品版本、源码提交与 MuJoCo 重力步进。Windows WSL2 的设备验收未运行。
