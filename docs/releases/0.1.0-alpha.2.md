# Lyapunov 0.1.0-alpha.2

This Linux x64 Alpha improves desktop-library and sandbox preparation in the default installer, desktop entry recovery, filesystem navigation, and workbench panel behavior. The installer requests normal system authorization when needed and preserves the previous version and user data if preparation fails.

The published archive omitted the native web frontend. Use Alpha3 for that packaging correction. Existing archives retain their original bytes and license notices.
