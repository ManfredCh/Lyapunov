# Lyapunov 0.2.4.1

本版把场景准备和 Isaac 后台工作流接入 Agent Graph。Linux x64 和 Windows WSL2 共用一个安装包。macOS 分批发布。

## 在工作台发现功能

打开资源库并展开「这台工作台能做什么？」，查看当前主机的运行时配置、可用工具和可复制的 Agent 指令。工作流使用现有会话和 Jobs，活动 campaign 记录工具调用。

## 四项工作流

- `asset_prepare_usd` 复用固定 SimFoundry 转换器，从自包含 GLB 生成带纹理、刚体和碰撞的原生 USD。输出可通过现有 `scene_import` 和 `asset_verify` 继续处理。
- `nurec_evaluate` 在独立 Isaac RTX 进程中核对同机位参考帧，返回配对数、PSNR 和 SSIM。
- `lab_mimic_run` 对固定笛卡尔夹具的带标注 HDF5 运行回放或扩增，返回实际通过与失败数及数据集。
- `simfoundry_match_poses` 复用上游 Stage 8，对已准备的 RGB-D 场景数据生成位姿候选。配准处于实验阶段。已知尺度的合成夹具中，中心误差约 3.4 cm，估计尺度约为真值的 61%。在应用候选前核对实际场景尺度和坐标。

运行条件、命令和上游源码见[场景与 Isaac 工作流](../ISAAC_SCENE_WORKFLOWS.zh-CN.md)。官网手册也提供录制、资产检查、Capture 键盘和 IRA 巡逻的用法。 [官网手册](https://vorynel.com/lyapunov/manual.html#agent-scene-workflows)
