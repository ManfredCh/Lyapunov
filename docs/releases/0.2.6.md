# Lyapunov 0.2.6 候选

工作台保留右侧扩展市场，并提供 `robotics-composition` 机器人组合入口。候选版本带入 18 项 AGY Robotics 技能、七项 MuJoCo API 指南和一个编排技能。各技能可按项目所需的 Scene、Sim、Jobs 和 Agent Graph 工具组合调用。 [接入清单](../../research/agy-robotics/README.md)

## 机器人组合工作流

- `robotics_lab` 使用现有原生 Job 执行 RGB 定位、Bi-RRT 避障、手眼标定拟合、视觉伺服计算、MJCF 动态审计、多视角渲染与原生调用记录的 MCAP 导出。
- 新建标准 MuJoCo 环境时同时安装机器人实验所需的图像和 MCAP 依赖。可通过 `LYAPUNOV_ROBOTICS_LAB_PYTHON` 选择兼容的独立环境。
- Linux x64 归档随固定 SDK 交付 Landlock 原生执行器，可在 Bubblewrap 不可用的支持系统上运行受限会话。
- Agent Graph 保留同种子配对、实测终态、独立安全评分和 Verifier 准入。腕相机纠偏、安全开爪和轨迹净空仍按显式参数启用。
- `playground_train_so101` 使用单独配置的 CPU Python 环境，调用 Playground 的 `SO101PickCube` 并保存训练日志和检查点。环境通过 `LYAPUNOV_PLAYGROUND_PYTHON` 配置。离线算法依赖可通过 `robotics_lab` 的 `probe` 检查。

## 当前证据

- Dev 实验覆盖双视角 RGB 到避障规划、SO‑101 原生抓放同种子回归和单轮 PPO 更新。逐项条件、成败、回放和哈希见 [研究记录](../research_log/README.md)。
- SO‑101、YAM、FR3 真机联调，整臂六自由度视觉闭环，T0–T4 扰动全量物理注入和 Playground 策略独立验收按对应设备和运行环境继续验证。
- 候选包的归档、独立解包和平台运行结果以对应构建原件为准。正式下载入口随发行确认后登记。
