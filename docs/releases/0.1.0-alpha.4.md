# Lyapunov 0.1.0α 发布说明

| 发布元数据 | 内容 |
| --- | --- |
| 用户发布名称 | 0.1.0α |
| 技术版本 | `0.1.0-alpha.4` |
| releaseId | `0.1.0-alpha.4` |
| 说明日期 | 2026-10-03 |

本批次修复首次请求文件锁才触发的 `system.node` 漏包。标准 Linux 打包入口从固定 DSH 源码构建 glibc 原生模块，并在归档前检查模块存在、格式及兼容要求；欢迎页与 Host 启动之外的实际文件锁行为有独立运行检查。Alpha3 的原生工作台前端构建、首页和静态资源缺件检查继续保留。

应用随包提供合法的 Noto Sans SC 中文字体，欢迎页、账号与退出界面使用当前选择的语言。Viewer 的失败、关闭和空场景展示互斥，主题状态卡片与顶部布局保持可读，失败时保留重试和停止入口。多个创建入口共用一份在途请求，真实创建、载入并采用新 Scene 后显示完成；物理就绪仍由既有引擎状态确认。

复用 GLB 资源时保留同版本显式碰撞用途、策略与预算，素材卡片展示派生和绑定状态，并从原物理面板恢复。Newton 在既有原生 MJCF／URDF 路线之外消费支持的 Scene collision：静态 OBJ 保留三角面与空区，动态 OBJ 按显式凸件装配，碰撞及刚体修改同步到同一世界的新代次。小 GLB 的真实 CPU 检查覆盖接触、关闭与恢复；机器人动作、通用 contacts／penetrations／topology、相机采集与 collisionPatches 仍未支持。

默认 MuJoCo 伴随环境、机器人与相机范围、英中 README、公司版权、七位作者、许可阈值及四份 Word 批注文案沿用既有发布。新归档使用独立技术版本 `0.1.0-alpha.4`，公开名仍为 `0.1.0α`；旧归档、URL 与标签保留。

发行范围为 Linux x64 Alpha。Windows 使用 WSL2 + WSLg 的 Linux 包路线，客户 WSLg 与各 GPU／发行版组合仍按实际验收；这次修复没有确定客户设备上 WebGL 创建失败的具体原因。

退出应用后重跑同一官网 curl 命令更新。安装器按实际检查执行正常系统授权并继续，检查通过才激活；安装成功并报告就绪后，由用户单独启动。版本目录、旧版本和包外用户数据保留，具体升级、回滚和数据备份见[安装手册](../install.md)。
