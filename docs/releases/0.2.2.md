# Lyapunov 0.2.2

0.2.2 is the full Linux x64 release that adds people and crowds to the workbench, first-class USD and SimReady assets, and explicit NVIDIA rendering on Linux. It is a complete distribution rebuilt from the tagged source.

## People and crowds

- Twelve bundled Microsoft Rocketbox adult characters (MIT) are available from **Create or import a human**. The default creates 20 people in a four-appearance mix, each with its own stride, walk clip and foot calibration; any single character or an imported template can be chosen instead.
- Licensed self-contained rigged GLB characters with in-place clips can be imported with explicit bone mapping, source axis, unit and heading calibration.
- People walk, run or stand along routes with loops, dwell time and limited turn rate. They stop conservatively for native obstacles, can yield to each other, and can plan around obstacles on a fixed plane when automatic navigation is enabled. Ragdoll mode provides a free-dynamics figure for applied forces.
- A new **Crowd** entry on the right tool rail opens one panel for creating people, checking whether the physics world is synchronized, starting or stopping each group or everyone, and applying per-person behavior presets: back and forth, square loop, or stand in place.
- The agent can create and direct crowds from natural language — for example "create 20 pedestrians with mixed appearances and let them walk back and forth for a minute", "make one group walk a 1.5 m square", or "stop everyone". The workbench buttons and the agent use the same operations.
- Human motion sampling can run on an NVIDIA GPU. Prepare the optional runtime with `./lyapunov install-provider mujoco --human-cuda`, then start the desktop with `LYAPUNOV_HUMAN_COMPUTE_DEVICE=cuda:0 ./lyapunov desktop`; the default installation stays on the CPU.

## USD and SimReady assets

- USD, USDA, USDC and USDZ files are first-class assets: the original layers, references, payloads, textures, materials, joints and physics properties are preserved. Assets support multiple instances, variants, portable save, relocation and reopen.
- The agent searches local assets first, then registered SimReady vendor libraries, verifies the pinned revision, license and bill of materials, and imports the complete native package. Hugging Face access uses the configured mirror only.
- The viewer renders UsdPreviewSurface textures, normal maps and UV transforms, and a standard MDL library can be registered from an installed NVIDIA SDK.

## Rendering and performance

- `./lyapunov desktop --nvidia-rendering` selects NVIDIA PRIME offload with ANGLE Vulkan for the desktop process and verifies the renderer actually in use.
- Crowd frames are produced faster, all walking people share one GPU computation per physics step when CUDA is selected, and large character libraries no longer grow the resource journal with every import.

## Install and previous versions

The website's default Linux manifest selects 0.2.2. The installer prepares the managed MuJoCo and policy runtimes as declared by the release manifest. User account files, engine preferences and workspaces are preserved during an upgrade.
