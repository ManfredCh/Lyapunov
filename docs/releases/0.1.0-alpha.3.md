# Lyapunov 0.1.0-alpha.3

This release includes the native DSH web frontend, fixing the blank workbench after the welcome page. The package builder runs the pinned frontend build and checks the entry page and referenced JavaScript/CSS before creating an archive.

## Installation

```sh
curl -fsSL https://vorynel.com/lyapunov/install.sh | sh
```

The default Linux x64 installer includes Node.js, Electron, pinned DSH and a private MuJoCo/Python companion. Published version manifests identify the original build source, archive size and checksum. Archives retain their published bytes and license notices.

## Known limitations

- Some installations cannot create a scene because the required native file-lock addon is absent.
- Chinese text can be missing on systems without a CJK fallback font.
- WSLg/VM environments need working WebGL support for the 3D viewer.
- Visual imports, collision derivation, world initialization and robot policy readiness are distinct steps.

These limitations remain under development; this source and documentation update does not replace the published runtime archive.
