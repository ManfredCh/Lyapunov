# Lyapunov 0.1.0α 发布说明

| 发布元数据 | 内容 |
| --- | --- |
| 用户发布名称 | 0.1.0α |
| 技术版本 | `0.1.0-alpha.3` |
| releaseId | `0.1.0-alpha.3` |
| 说明日期 | 2026-10-03 |

本批次修复Alpha2发行包遗漏原生工作台前端的问题。标准Linux打包入口现在从固定DSH源码调用原前端构建脚本，在收闭复制之前验证首页及其本地启动资源，并在真实发行stage归档之前再次拒绝缺件。新归档使用独立技术版本 `0.1.0-alpha.3`，公开名仍为 `0.1.0α`；旧Alpha1／Alpha2归档、URL与标签保留。

桌面面板、文件导航、默认同curl安装的系统依赖／沙箱授权和旧同产品入口升级，以及四份Word批注文案，沿用[Alpha2说明](0.1.0-alpha.2.md)。SDK52、README英中、公司版权、七作者与许可阈值保持；默认MuJoCo仍使用已批准的版本化伴随运行环境。

本批次源码、自动化检查、真实前端构建、归档首页／资产与包内Guest Host页面结果分别记录。Host启动就绪和欢迎页成功不能替代工作台页面验收；客户具体桌面、WSLg、输入、渲染和物理组合仍按各自实际结果确认，不将静态资源HTTP成功记为完整客户GUI通过。

使用默认安装器的用户退出应用后重跑同一官网curl命令更新。版本目录、旧版本及包外用户数据保留；安装器按实际检查执行正常系统授权并继续，检查通过才激活，成功后由用户单独启动。具体升级、回滚和数据备份见[安装手册](../install.md)。
