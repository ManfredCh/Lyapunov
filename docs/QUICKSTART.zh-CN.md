# Lyapunov入门教程

[English](QUICKSTART.md) | [简体中文](QUICKSTART.zh-CN.md)

杭州奇异宇宙人工智能有限公司出品。本文为Linux x64 Alpha操作指南，案例给输入、动作与读回判据，不声明最终包已完成演示。自然语言例子需要登录或Guest显式配置自有provider；推荐原生工具/控件。

## 地面与箱子的受控MuJoCo

**输入：** 空Scene、静态地面、动态箱子；托管MuJoCo和所需渲染依赖就绪。

1. 用原生场景/Blender工具建立有尺寸的地面和箱子。
2. 选择MuJoCo，检查重力、用途与碰撞，初始化暂停world。
3. 显式推进20步或约定的短有界动作，读取前后状态，再停止。
4. 保存Scene；需要采集时另确认渲染就绪。

**可用请求例：**

```text
建立静态地面和边长0.2米的动态箱子。用MuJoCo初始化为暂停，先报告world与箱子状态；只推进20步，读取前后位姿、stepIndex和simTime后停止。
```

**核对输出：**

- 实际engineId/world/Scene revision一致。
- 显式推进后步数/时间和箱子状态真实变化。
- 需要落地验证时另约定足够但有界的步数并读取contact；不由Viewer动画推断。

不是已执行演示；缺SDK/渲染/物理组件时报告阻断。

## Panda手动关节与TCP

**输入：** 官方Panda原生模型、完整mesh/texture/actuator闭包、当前引擎可用控制。

1. 从官方根导入Panda MJCF/URDF及include/mesh/texture闭包，读取真实关节/site/TCP与限位。
2. 初始化暂停；选择实际可控关节，做一个小幅有界动作后停止。
3. 读取真实关节反馈与TCP位姿/定义。
4. 需要末端目标运动时先检查相应规划/IK能力；设置TCP定义不等于执行末端轨迹。

**可用请求例：**

```text
列出当前Panda的可控关节和限位，显示TCP位姿。只对第一个可控机械臂关节做限位内的小幅动作，停止后报告误差；不要自动执行抓取或整套policy。
```

**核对输出：**

- 实际可控关节/限位与动作回执一致。
- 停止确认、关节反馈与TCP信息可读取。
- 如走规划，检查计划与实际执行结果分别返回。

不承诺所有Panda文件/引擎或任意抓放；policy另prepare/match。

## 相机、RGB-D与标注采集

**输入：** 有可见物体的Scene、就绪MuJoCo或支持相机的引擎、渲染后端。

1. 从真实body/preset选parent，不猜腕部offset；保存world或parent相机/当前视角并等待sync和native读回。
2. 应用Scene修改/同步，列出真实命名相机并选择一台。
3. 采集RGB-D与标定，在有效像素上标注并修改说明。
4. 保存/重新打开标注；导出采集或数据集并返回实际路径。

**可用请求例：**

```text
把当前视角保存为场景相机，同步到就绪的世界后采集RGB-D和标定。用箱子上的有效像素与真实深度创建标注，修改说明并保存，再导出采集和标注。
```

**核对输出：**

- captureId、K/外参、分辨率、米制深度与来源frame一致。
- 修改后重开标注的文字/目标/位置保留。
- 导出文件与manifest引用对应实际采集。

Viewer截图和引擎标定帧分别登记；无效深度不编造三维点。

## 室内视觉与碰撞配准

**输入：** 自己有权使用的室内GLB或Gaussian视觉件，以及配准碰撞几何。

1. 检查方向/比例/轴，分别登记视觉与static/environment碰撞。
2. 等待物理派生status=ok，核对fillInterior:false、实际voxel pitch与预算；保留源表面和空区。
3. 同步到暂停world，用小探针或已支持机器人做有界接触/通道检查并停止。
4. 保存Scene与碰撞来源/参数；预算超限或窄孔不清晰时报告。

**可用请求例：**

```text
检查这间房间的视觉与碰撞是否配准。保留室内空区和门洞，不把房间烘成实心盒；只做一个墙面接触与门洞净空的有界检查，报告实际位移/contact和预算后停止。
```

**核对输出：**

- 视觉与碰撞对应同一实体变换/单位/Scene版本。
- 实际空点负对照与墙面接触正对照；另核真实通道净空，不能用interiorPreserved标记代签。
- 有限pitch/预算与剩余未覆盖区域明确。

不是全室通行/导航任务已完成，不宣完整B1或全部窄孔通过。

已有原生自由落体检查可在安装目录以实际入口运行；它单独检查MuJoCo，不能替代机器人或全部场景结果：

```sh
./lyapunov physics-check --managed-sdk
```

完整环境/数据/回滚要求见[安装手册](https://vorynel.com/lyapunov/guide.html)，类型入口见[中文README](../README.zh-CN.md)。
